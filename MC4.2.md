# Topic: MC4.2 Angles in Triangles & Quadrilaterals

The interior angles of any triangle sum to $180^\circ$ and its exterior angle equals the sum of two opposite interior angles; the interior angles of any convex quadrilateral sum to $360^\circ$.

---

### 1. Polygons Angle Breakdown

| Polygon Type | Angle Sum / Property | Key Feature |
| --- | --- | --- |
| Any Triangle | $A + B + C = 180^\circ$ | Sum of interior angles is always $180^\circ$. |
| Triangle Exterior Angle | $d = A + B$ | Exterior angle equals sum of two opposite interior angles. |
| Isosceles Triangle | Base angles equal ($A = B$) | Angles opposite the two equal sides are equal. |
| Equilateral Triangle | $A = B = C = 60^\circ$ | All 3 sides and all 3 interior angles are equal. |
| Quadrilateral | $A + B + C + D = 360^\circ$ | Sum of interior angles is always $360^\circ$ ($2 \times 180^\circ$). |

---

### 2. Geometry & ASCII Diagram

```
                 C
                / \
               /   \
              /     \
             /       \
  ---------*----------*--------->
  Ext d   A            B
```

* **Exterior Angle Theorem:** Extending side $AB$ creates exterior angle $d$, where $d = C + A$ (if extended at $B$).
* **Isosceles Base Angles:** In triangle with sides $AC = BC$, base angles $\angle CAB = \angle CBA$.
* **Quadrilateral Triangulation:** Any quadrilateral can be split into 2 triangles by a diagonal ($2 \times 180^\circ = 360^\circ$).

$$A + B + C = 180^\circ \quad \text{and} \quad d_{\text{ext}} = A + C$$

### 3. Worked Example

> **Question:**
> 1. In isosceles triangle $PQR$, $PQ = PR$ and top vertex angle $P = 40^\circ$. Calculate base angle $Q$.
> 2. Quadrilateral $ABCD$ has interior angles $A = 85^\circ$, $B = 110^\circ$, and $C = 75^\circ$. Calculate interior angle $D$.

**Step 1: Calculate Base Angle in Isosceles Triangle $PQR$**

1. Subtract vertex angle $P = 40^\circ$ from $180^\circ$:

$$\text{Sum of base angles } Q + R = 180^\circ - 40^\circ = 140^\circ$$

2. Divide by $2$ since base angles $Q$ and $R$ are equal:

$$Q = \frac{140^\circ}{2} = 70^\circ$$

**Step 2: Calculate Missing Angle in Quadrilateral $ABCD$**

1. Sum known angles of quadrilateral:

$$\text{Sum} = 85^\circ + 110^\circ + 75^\circ = 270^\circ$$

2. Subtract from total quadrilateral sum ($360^\circ$):

$$D = 360^\circ - 270^\circ = 90^\circ$$

3. **Base Angle $Q$:** $70^\circ$
4. **Quadrilateral Angle $D$:** $90^\circ$

---

### 4. Common Examiner Traps

* **Assuming Equal Angles Without Proof:** Assuming a triangle is isosceles because it looks visually symmetrical, without explicit tick marks or angle values.
* **Exterior Angle Over-addition:** Calculating exterior angle as $180^\circ - \text{interior}$ and adding it to other angles unnecessarily.
* **Quadrilateral Sum Error:** Using $180^\circ$ instead of $360^\circ$ for quadrilaterals.
