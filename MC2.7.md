# Topic: MC2.7 Linear Graphs

A linear graph is a straight-line representation of the equation \(y = mx + c\), where \(m\) represents the gradient (steepness/rate of change) and \(c\) represents the \(y\)-intercept.

---

### 1. Linear Graph Components Breakdown

| Linear Feature | Formula / Condition | Geometric Meaning |
| --- | --- | --- |
| Gradient (\(m\)) | \(m = \frac{y_2 - y_1}{x_2 - x_1} = \frac{\text{rise}}{\text{run}}\) | Steepness and direction (+ is upward, - is downward). |
| \(y\)-intercept (\(c\)) | Set \(x = 0 \implies (0, c)\) | Point where line crosses vertical \(y\)-axis. |
| Parallel Lines | \(m_1 = m_2\) | Lines with equal gradients never intersect. |

---

### 2. Anatomy of Linear Graph Equation y = mx + c

```
                       y-axis
                         |       / Line: y = 2x + 3
                         |      /
                 (0,3) --+--   / (Gradient m = 2)
                         |   /
                         | /
          ---------------+--------------- x-axis
                         |
```

* **Gradient (\(m\)):** Change in vertical distance divided by change in horizontal distance between two points on the line.
* **Intercept (\(c\)):** The constant term defining the vertical shift from the origin.

$$m = \frac{\text{Rise}}{\text{Run}} = \frac{y_2 - y_1}{x_2 - x_1}$$

---

### 3. Worked Example

> **Question:**
> A straight line passes through points \(A(2, 1)\) and \(B(6, 9)\).
> 1. Find the gradient of line \(AB\).
> 2. Find the equation of line \(AB\) in the form \(y = mx + c\).

**Step 1: Calculate the gradient m**

1. Apply gradient formula using points \((x_1, y_1) = (2, 1)\) and \((x_2, y_2) = (6, 9)\):

$$m = \frac{9 - 1}{6 - 2}$$

2. Simplify fraction:

$$m = \frac{8}{4} = 2$$

**Step 2: Determine y-intercept c and state line equation**

1. Substitute \(m = 2\) and point \((2, 1)\) into \(y = mx + c\):

$$1 = 2(2) + c$$

2. Solve for \(c\):

$$1 = 4 + c \implies c = 1 - 4 = -3$$

3. **Key result 1:** Gradient \(m = 2\).
4. **Key result 2:** Equation of line is \(y = 2x - 3\).

---

### 4. Common Examiner Traps

* **Gradient Ratio Inversion:** Calculating \(\frac{\text{run}}{\text{rise}} = \frac{x_2 - x_1}{y_2 - y_1}\) instead of \(\frac{\text{rise}}{\text{run}}\).
* **Sign Confusion in Subtraction:** Subtracting negative coordinates incorrectly, e.g., \(5 - (-3) = 2\) instead of \(8\).
