## 1. Core Intuition & Mental Model ("What is it?")
A function graph provides a complete visual representation of the mathematical relationship between an independent input variable ($x$) and a dependent output variable ($y$). By substituting a set of $x$-values into a function equation, we construct a table of values and plot ordered pairs $(x, y)$ on Cartesian axes to reveal the characteristic shape of the function curve.

Think of plotting a function graph like connect-the-dots. Each $(x,y)$ pair is an exact coordinate pin dropped on a map. Linear functions ($y = ax + b$) form straight lines; quadratic functions ($y = \pm x^2 + ax + b$) form smooth U-shaped or n-shaped parabolas; reciprocal functions ($y = \frac{a}{x}$) split into two hyperbolic curves that never touch the axes ($x \neq 0$).

## 2. Key Definitions, Principles & Formulas
- **Linear Functions ($y = ax + b$)**:
  - Graph shape: Straight line.
  - $a$ = gradient (steepness), $b$ = $y$-intercept.
- **Quadratic Functions ($y = \pm x^2 + ax + b$)**:
  - Graph shape: Parabola.
  - Positive $x^2$ coefficient ($+x^2$): U-shaped curve with a minimum turning point.
  - Negative $x^2$ coefficient ($-x^2$): n-shaped curve with a maximum turning point.
  - $b$ = $y$-intercept where the graph crosses the vertical axis $(0, b)$.
- **Reciprocal Functions ($y = \frac{a}{x}, x \neq 0$)**:
  - Graph shape: Hyperbola with two separate symmetrical branches.
  - Asymptote at $x = 0$ (vertical $y$-axis) and $y = 0$ (horizontal $x$-axis).

> 💡 **Exam Tip**: When plotting quadratic curves, join points with a smooth, continuous freehand curve. NEVER use a ruler to connect points on a parabola!

> ⚠️ **Common Misconception**: In reciprocal functions like $y = \frac{6}{x}$, substituting $x = 0$ is mathematically undefined ($\frac{6}{0}$ does NOT exist). Never plot a point on the line $x = 0$.

## 3. Step-by-Step Method & Worked Exam Demonstration

### Worked Example 1: Table of Values and Plotting a Quadratic Graph
Complete the table of values for the quadratic function $y = x^2 - 2x - 3$ for $-2 \leqslant x \leqslant 4$, and identify the key features.

| $x$ | $-2$ | $-1$ | $0$ | $1$ | $2$ | $3$ | $4$ |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| $y$ | | $0$ | $-3$ | | $-3$ | $0$ | |

#### Solution:
- **Step 1: Calculate $y$ for $x = -2$ (remembering to use brackets for negative squaring).**
  $$y = (-2)^2 - 2(-2) - 3 = 4 + 4 - 3 = 5$$
- **Step 2: Calculate $y$ for $x = 1$.**
  $$y = (1)^2 - 2(1) - 3 = 1 - 2 - 3 = -4$$
- **Step 3: Calculate $y$ for $x = 4$.**
  $$y = (4)^2 - 2(4) - 3 = 16 - 8 - 3 = 5$$
- **Step 4: Present the completed table of values.**

| $x$ | $-2$ | $-1$ | $0$ | $1$ | $2$ | $3$ | $4$ |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| $y$ | **$5$** | $0$ | $-3$ | **$-4$** | $-3$ | $0$ | **$5$** |

- **Step 5: Identify key graph features from table values.**
  - **$y$-intercept**: $(0, -3)$ where $x = 0$.
  - **$x$-intercepts (roots)**: $(-1, 0)$ and $(3, 0)$ where $y = 0$.
  - **Minimum Turning Point**: $(1, -4)$, located symmetrically midway between the roots.

## 4. Common Misconceptions & Diagnostic Exam Pitfalls
- **Negative Squaring Error**: Evaluating $-2^2 - 2(-2) - 3$ as $-4 + 4 - 3 = -3$ instead of $+4 + 4 - 3 = 5$. Always square negative numbers inside brackets!
- **Plotting Point Misplacement**: Misreading scale divisions on grid axes (e.g. counting 1 small square as 1 unit when the scale is 2 small squares per unit).
- **Flat Bottoms on Parabolas**: Drawing a flat line between bottom points instead of a smooth curved vertex.

## 5. Key Terms & Revision Summary
| Function Type | General Equation | Characteristic Shape | Key Feature |
| :--- | :--- | :--- | :--- |
| **Linear** | $y = ax + b$ | Straight Line | Constant gradient $a$ |
| **Quadratic ($+x^2$)** | $y = x^2 + ax + b$ | U-shaped Parabola | Minimum turning point |
| **Quadratic ($-x^2$)** | $y = -x^2 + ax + b$ | n-shaped Parabola | Maximum turning point |
