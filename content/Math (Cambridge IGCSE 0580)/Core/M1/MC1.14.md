# C1.14 Calculator Skills & Rounding Rules (Core Tier)

## Mastering Scientific Calculators & Cambridge Accuracy Standards

A scientific calculator is an indispensable tool in Cambridge IGCSE Mathematics. However, using a calculator incorrectly—such as failing to enter multi-term fractions using brackets, or rounding intermediate steps too early—can easily cause you to lose final accuracy marks.

---

## Cambridge IGCSE Standard Accuracy Rules

Unless a question explicitly specifies a different degree of accuracy (e.g. "give your answer to 2 decimal places"):

1. **Non-Exact Numerical Values**: Round to **3 significant figures (3 s.f.)**.
2. **Angles in Degrees**: Round to **1 decimal place (1 d.p.)**.
3. **Exact Values**: State exact integers or fractions without rounding (e.g., $\frac{3}{4}$, $2.5$, $12$).
4. **Value of $\pi$**: Use the dedicated $\pi$ key on your calculator, or use $3.142$.

---

## Key Calculator Operations & Buttons

| Button Symbol | Function / Operation | Usage Example & Instructions |
| :--- | :--- | :--- |
| `[a b/c]` or `[■/■]` | Fraction Key | Inputs exact fractions and mixed numbers. Use arrow keys to navigate numerator and denominator. |
| `[x²]` / `[xⁿ]` | Exponents / Powers | Evaluates powers. `5 [xⁿ] 4` computes $5^4 = 625$. |
| `[√]` / `[ⁿ√]` | Square / $n$-th Root | Computes roots. `3 [ⁿ√] 64` computes $\sqrt[3]{64} = 4$. |
| `[x10ⁿ]` or `[EXP]` | Scientific Notation | Inputs standard form. `4.5 [x10ⁿ] 6` enters $4.5 \times 10^6$. |
| `[S⇔D]` | Fraction-Decimal Toggle | Converts display output between exact fractions and decimals. |
| `[ANS]` | Previous Answer | Stores the exact unrounded value from the previous line. Use this to prevent premature rounding! |

## Step-by-Step Worked Exam Demonstrations

### Question 1: Complex Multi-Term Calculator Calculation
Calculate the value of:
$$\frac{\sqrt{4.8^2 + 12.6}}{9.4 - 3.1 \times 1.8}$$

(a) Write down the full calculator display.  
(b) Write your answer to 3 significant figures.

#### Solution & Line-by-Line Annotations

**(a) Evaluating full calculator display:**

1. **Method 1 (Using fraction key `[■/■]`)**:
   Input numerator $\sqrt{4.8^2 + 12.6}$ into top box, and denominator $9.4 - 3.1 \times 1.8$ into bottom box.

2. **Method 2 (Using brackets)**:
   Input as: `( √( 4.8² + 12.6 ) ) ÷ ( 9.4 - 3.1 × 1.8 )`

3. **Full Display Output**:
   $$1.53037943...$$

**(b) Rounding to 3 significant figures:**
1. Identify 1st, 2nd, and 3rd significant figures:
   * 1st s.f. = $1$
   * 2nd s.f. = $5$
   * 3rd s.f. = $3$
2. Look at 4th figure ($0 < 5 \implies$ round down):
   $$\text{Final Answer} = 1.53$$

## Examiner Traps & Common Candidate Pitfalls

* **Mistake: Premature Rounding**  
  *Why it happens*: Rounding intermediate steps to 2 s.f. during a multi-step calculation.  
  *The Correction*: Retain full unrounded calculator values in memory (or use `[ANS]`) until the final line. Round **only** the final numerical answer.

* **Mistake: Missing Denominator Parentheses**  
  *Why it happens*: Typing `√... ÷ 9.4 - 3.1 × 1.8` without brackets.  
  *The Correction*: The calculator will divide by $9.4$ first, then subtract $3.1 \times 1.8$. Always wrap multi-term denominators in brackets: `÷ (9.4 - 3.1 × 1.8)`.
