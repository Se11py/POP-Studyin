# C1.4 Fractions, Decimals & Percentages (Core Tier)

## Three Languages for the Same Mathematical Value

Fractions, decimals, and percentages are three different mathematical "languages" used to describe parts of a whole quantity:
* **Fractions ($\frac{a}{b}$)**: Describe a portion divided into equal parts (e.g., $\frac{3}{4}$ means 3 parts out of 4).
* **Decimals ($0.x$)**: Describe fractional parts scaled to powers of ten ($10, 100, 1000$).
* **Percentages ($\%$)**: Describe parts out of one hundred ($100$).

Being able to convert fluidly between these forms allows you to compare different quantities quickly, solve financial problems, and scale measurements.

---

## Conversion Rules & Equivalent Values

### 1. The Conversion Triad Rules

$$\text{Fraction} \xrightarrow{\quad \text{Numerator} \div \text{Denominator} \quad} \text{Decimal} \xrightarrow{\quad \times 100\% \quad} \text{Percentage}$$

$$\text{Percentage} \xrightarrow{\quad \div 100 \quad} \text{Decimal} \xrightarrow{\quad \text{Place value fraction \& simplify} \quad} \text{Fraction}$$

* **Fraction to Decimal**: Divide top number by bottom number ($\frac{3}{8} = 3 \div 8 = 0.375$).
* **Decimal to Percentage**: Multiply by $100\%$ ($0.375 \times 100\% = 37.5\%$).
* **Percentage to Fraction**: Write over $100$ and simplify by cancelling common factors ($45\% = \frac{45}{100} = \frac{9}{20}$).

## Step-by-Step Worked Exam Demonstrations

### Question 1: Converting and Ordering Quantities
Arrange the following numbers in order of size, starting with the smallest:
$$\frac{7}{10}, \quad 0.68, \quad 72\%, \quad \frac{2}{3}$$

#### Solution & Line-by-Line Annotations

1. Convert all numbers into decimal form to $4$ decimal places so they can be compared directly:
   * $\frac{7}{10} = 7 \div 10 = 0.7000$
   * $0.68 = 0.6800$
   * $72\% = 72 \div 100 = 0.7200$
   * $\frac{2}{3} = 2 \div 3 = 0.6667$

2. Compare decimal magnitudes:
   $$0.6667 < 0.6800 < 0.7000 < 0.7200$$

3. Write down the final list in ascending order using the **original numbers** given in the question:
   $$\frac{2}{3}, \quad 0.68, \quad \frac{7}{10}, \quad 72\%$$

---

### Question 2: Mixed Number Conversions
Convert $3\frac{2}{5}$ into an improper fraction, then express it as a decimal.

#### Solution & Line-by-Line Annotations

1. Convert mixed number to improper fraction:
   $$3\frac{2}{5} = \frac{(3 \times 5) + 2}{5} = \frac{15 + 2}{5} = \frac{17}{5}$$

2. Divide numerator by denominator:
   $$\frac{17}{5} = 17 \div 5 = 3.4$$

## Examiner Traps & Common Candidate Pitfalls

* **Mistake: Listing Decimal Values in the Final Answer**  
  *Why it happens*: Candidates write $0.6667, 0.68, 0.7, 0.72$ on the answer line.  
  *The Correction*: Mark schemes award the final accuracy mark ONLY if you rewrite the **original forms** given in the prompt ($\frac{2}{3}, 0.68, \frac{7}{10}, 72\%$).

* **Mistake: Misunderstanding Mixed Number Decimal Placement**  
  *Why it happens*: Candidates assume $3\frac{2}{5} = 3.25$ because they see the digit $2$.  
  *The Correction*: Always evaluate the fractional part separately ($\frac{2}{5} = 0.4$), so $3\frac{2}{5} = 3.4$.
