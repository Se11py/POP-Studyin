# C1.13 Percentages, Multipliers & Percentage Change (Core Tier)

## What Is a Percentage and How Do Multipliers Work?

A **percentage** is a fraction expressed with a denominator of $100$. The symbol $\%$ literally means "per hundred".

While basic percentage calculations can be done by finding $10\%$ or $1\%$, Cambridge IGCSE examination questions are solved fastest and most accurately using **decimal multipliers**. A decimal multiplier combines the original amount ($100\% = 1.0$) with the percentage change in a single multiplication step.

---

## Decimal Multipliers Reference Table

| Goal / Operation | Percentage Formula | Decimal Multiplier | Example Calculation |
| :--- | :--- | :--- | :--- |
| **Find $15\%$ of an amount** | $\frac{15}{100}$ | **$\times 0.15$** | $0.15 \times \$200 = \$30$ |
| **Increase by $15\%$** | $100\% + 15\% = 115\% \rightarrow \frac{115}{100}$ | **$\times 1.15$** | $\$200 \times 1.15 = \$230$ |
| **Decrease by $15\%$** | $100\% - 15\% = 85\% \rightarrow \frac{85}{100}$ | **$\times 0.85$** | $\$200 \times 0.85 = \$170$ |
| **Increase by $8\%$** | $100\% + 8\% = 108\% \rightarrow \frac{108}{100}$ | **$\times 1.08$** | $\$500 \times 1.08 = \$540$ |
| **Decrease by $6\%$** | $100\% - 6\% = 94\% \rightarrow \frac{94}{100}$ | **$\times 0.94$** | $\$500 \times 0.94 = \$470$ |

---

## Percentage Change Formula

To find the percentage increase or decrease between an original value and a new value:

$$\text{Percentage Change} = \frac{\text{Change}}{\text{Original Value}} \times 100\%$$

where $\text{Change} = |\text{New Value} - \text{Original Value}|$.

---

## Step-by-Step Worked Exam Demonstrations

### Question 1: Percentage Increase & Decrease
(a) Increase $\$350$ by $18\%$.  
(b) A coat originally priced at $\$120$ is reduced by $25\%$ in a sale. Calculate the sale price.

#### Solution & Line-by-Line Annotations

**(a) Increasing $\$350$ by $18\%$:**
1. Determine multiplier: $100\% + 18\% = 118\% = 1.18$.
2. Multiply original value by multiplier:
   $$\text{New Value} = \$350 \times 1.18 = \$413$$

**(b) Calculating sale price (25% reduction):**
1. Determine multiplier: $100\% - 25\% = 75\% = 0.75$.
2. Multiply original price by multiplier:
   $$\text{Sale Price} = \$120 \times 0.75 = \$90$$

---

### Question 2: Calculating Percentage Change
A house was purchased in 2018 for $\$240\,000$ and sold in 2024 for $\$288\,000$. Calculate the percentage profit.

#### Solution & Line-by-Line Annotations

1. **Step 1: Calculate absolute increase (change)**:
   $$\text{Change} = \$288\,000 - \$240\,000 = \$48\,000$$

2. **Step 2: Apply Percentage Change formula**:
   $$\text{Percentage Profit} = \frac{\text{Change}}{\text{Original Value}} \times 100\%$$
   $$\text{Percentage Profit} = \frac{\$48\,000}{\$240\,000} \times 100\% = \frac{1}{5} \times 100\% = 20\%$$

---

## Examiner Traps & Common Candidate Pitfalls

* **Mistake: Dividing by the New Value Instead of Original**  
  *Why it happens*: In Question 2, dividing $\$48\,000$ by the new price $\$288\,000$ ($\frac{48000}{288000} = 16.7\%$).  
  *The Correction*: The denominator MUST always be the **Original Value** before the change occurred.

* **Mistake: Incorrect Multiplier for Single-Digit Percentages**  
  *Why it happens*: Writing an $8\%$ increase multiplier as $1.8$ instead of $1.08$.  
  *The Correction*: $1.8$ represents an $80\%$ increase! For single-digit percentages, use a leading zero: $8\% \rightarrow 0.08 \implies \text{Increase multiplier} = 1.08$.
