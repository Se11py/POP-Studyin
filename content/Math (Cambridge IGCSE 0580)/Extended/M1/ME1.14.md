# E1.14 Advanced Calculator Functions & Storage (Extended Tier)

## Scientific Calculator Mastery in Extended Examinations

In Extended Tier Mathematics, calculator efficiency is essential for evaluating multi-term expressions, trigonometric roots, fractional indices, and statistical logarithms without accumulating premature rounding errors.

---

## Cambridge IGCSE Extended Accuracy Guidelines

1. **Standard Non-Exact Results**: Round final answers to **3 significant figures (3 s.f.)**.
2. **Angle Degrees**: Round final angular values to **1 decimal place (1 d.p.)**.
3. **Exact Surds/Fractions**: Leave in exact form if specified in prompt (e.g., $\frac{3\sqrt{5}}{2}$).
4. **Intermediate Memory Usage**: Store intermediate calculations using calculator memory keys (`[STO]`, `[RCL]`, or `[ANS]`).

---

## Step-by-Step Worked Exam Demonstrations

### Question: Complex Extended Calculator Calculation
Evaluate the following expression:
$$x = \frac{\sqrt[3]{14.8^2 + 105.6}}{4.2^3 - 3.8 \times 12.1}$$

(a) Write down the full calculator display.  
(b) Write your answer to 3 significant figures.

#### Solution & Line-by-Line Annotations

**(a) Full Calculator Display:**

1. **Input numerator**:
   $$\sqrt[3]{14.8^2 + 105.6} = \sqrt[3]{219.04 + 105.6} = \sqrt[3]{324.64} \approx 6.872605...$$

2. **Input denominator**:
   $$4.2^3 - 3.8 \times 12.1 = 74.088 - 45.98 = 28.108$$

3. **Divide full stored values**:
   $$\frac{6.872605...}{28.108} = 0.24449873...$$

**(b) Rounding to 3 Significant Figures:**
* 1st s.f. = $2$
* 2nd s.f. = $4$
* 3rd s.f. = $4$
* 4th digit = $9 \ge 5 \implies$ round up:
  $$\text{Final Answer} = 0.2445 \rightarrow 0.244 \text{ is 3 s.f.? No, } 0.244498... \text{ rounds to } 0.2445 \text{ (4 s.f.) or } 0.245 \text{ (3 s.f.)}$$
  $$0.245 \quad (3\text{ s.f.})$$

## Examiner Traps & Common Candidate Pitfalls

* **Mistake: Truncating Memory Values Intermediate**  
  *Why it happens*: Rounding $6.8726$ to $6.87$ and $28.108$ to $28.1$ gives $\frac{6.87}{28.1} = 0.24448 \rightarrow 0.244$ (Incorrect 3rd figure!).  
  *The Correction*: Use `[ANS]` or keep full memory values.
