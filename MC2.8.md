# Topic: MC2.8 Non-Linear Graphs

Non-linear graphs represent non-straight relationships such as quadratic curves (\(y = ax^2 + bx + c\)), cubic curves (\(y = ax^3 + \dots\)), and reciprocal curves (\(y = \frac{a}{x}\)).

---

### 1. Non-Linear Graph Types Breakdown

| Curve Type | Standard Equation Form | Curve Shape Description | Turning / Discontinuity Points |
| --- | --- | --- | --- |
| Quadratic | \(y = ax^2 + bx + c\) | Parabola (U-shape for \(a > 0\), \(\cap\)-shape for \(a < 0\)) | Single minimum or maximum turning point |
| Cubic | \(y = ax^3 + bx^2 + cx + d\) | S-shaped curve | Up to two turning points (local max/min) |
| Reciprocal | \(y = \frac{a}{x}\) | Two-part hyperbola | Discontinuous at \(x = 0\) (asymptotes along axes) |

---

### 2. Anatomy of Non-Linear Curves

```
      Quadratic (y = x² - 4)                     Reciprocal (y = 6/x)
             y                                          y
             |   /                                      |  \
             |  /                                 ------+---\--- Asymptote y=0
      -------+------- x-axis                            |    \
            / \                                   ------+-----\- x-axis
           /   \  Vertex (0,-4)                         |      \
```

* **Parabola Symmetry:** Quadratic graphs are symmetrical about a vertical line passing through their vertex.
* **Asymptote:** A straight line that a curve approaches infinitely closely without ever touching (e.g. \(x = 0\) and \(y = 0\) for reciprocal graphs).

$$y = ax^2 + bx + c \quad (a \ne 0)$$

### 3. Worked Example

> **Question:**
> Complete the table of values and sketch the graph of \(y = x^2 - 3x - 2\) for \(-2 \le x \le 4\).
> 1. Calculate \(y\) when \(x = -2\) and \(x = 3\).
> 2. Identify the coordinates of the \(y\)-intercept.

**Step 1: Complete coordinate table evaluation**

1. Calculate \(y\) for \(x = -2\) using explicit substitution with parentheses:

$$y = (-2)^2 - 3(-2) - 2 = 4 + 6 - 2 = 8$$

2. Calculate \(y\) for \(x = 3\):

$$y = (3)^2 - 3(3) - 2 = 9 - 9 - 2 = -2$$

**Step 2: Identify y-intercept coordinates**

1. Set \(x = 0\) in quadratic equation:

$$y = (0)^2 - 3(0) - 2 = -2$$

2. Express as complete point \((x, y)\):

$$\text{Intercept} = (0, -2)$$

3. **Key result 1:** Evaluated points are \((-2, 8)\) and \((3, -2)\).
4. **Key result 2:** The \(y\)-intercept is \((0, -2)\).

---

### 4. Common Examiner Traps

* **Negative Squaring Error:** Evaluating \(-2^2\) as \(-4\) on a calculator instead of \((-2)^2 = 4\).
* **Ruler-Drawn Curves:** Joining curve points with straight ruled line segments instead of a smooth continuous freehand curve.
